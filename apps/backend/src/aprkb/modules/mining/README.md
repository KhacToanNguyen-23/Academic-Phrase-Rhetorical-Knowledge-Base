# Mining scope

Implement rule-based sentence extraction in the worker with pending candidates, source provenance and two-round review. `NLP_ENGINE=regex` remains the default; `NLP_ENGINE=spacy` runs the rule-first boundary resolver and stores token features at ingest. The reporting-verb path consumes valid stored tokens and preserves its existing output; only its misses are offered to the versioned, closed-world construction registry. Mining stays spaCy-free and checks mining rights before source access. The policy-gated imperative branch and construction coverage remain provisional pending reviewed real-article samples. See [ADR-0007](../../../../../../doc/adr/0007-rule-based-slot-abstraction.md), [ADR-0010](../../../../../../doc/adr/0010-spacy-ingest-token-features.md), and [ADR-0011](../../../../../../doc/adr/0011-construction-registry-and-frame-statistics.md).

The `extraction` module (`/extract` page) queues this mining per import batch and lets one reviewer accept phrases into `approved_phrases`; see [ADR-0009](../../../../../../doc/adr/0009-phrase-extraction-page.md).

The spaCy shared-token-feature spike is recorded in [the round-1 report](../../../../../../plans/reports/261104-spacy-nlp-spike-report.md), [the round-2 report](../../../../../../plans/reports/261104-spacy-nlp-spike-round2-report.md), [the phase-2 report](../../../../../../plans/reports/261104-spacy-phase2-report.md), and [the phase-3 report](../../../../../../plans/reports/261104-spacy-phase3-report.md).

`make phrase-stats ARGS="--focal-batch <uuid> --background all-other"` reports document frequency for masked candidate frames. It excludes rejected candidates, counts each candidate once per article, and never reads or prints sentence text. Results are descriptive; when the focal set is small or the background is empty, only the recurrence ranking is shown. `python apps/backend/scripts/mining_trial_report.py <directory> --blob-root <blob-root>` runs the local aggregate-only spaCy trial. Before opening file contents, it verifies every relative blob key against an article whose license metadata allows mining. Optional Windows-only `--dump <path>` writes imperative and coordinated sentences for manual review to a new ignored file directly under `tmp/`; stdout and the committed report remain counts-only.
