# Section label evaluation set

`gold/draft-50.yaml` is an AI-generated draft containing one entry per de-duplicated
article. Each entry lists heading text and a proposed section code; each heading is marked
`status: ai_draft`. It contains no section body text. The directory is git-ignored while
the owner decides whether heading text may be retained.

This draft is not approved gold. A human must review and approve every heading label before
the set is used to make acceptance claims or tune the section detector. Reports measured
against this draft are diagnostic only.
